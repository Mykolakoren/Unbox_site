## Тёмная тема (02.11)

Включается только выбором человека (профиль → «Оформление», на этом устройстве); нет выбора — светлая.
Значения — блок `:root[data-theme="dark"]` в `src/index.css` и конец `src/design/tokens.ts`, они обязаны совпадать.
Смена темы перезагружает страницу.

- Цвет брать из токенов: тогда экран работает в обеих темах сам. Нужен цвет вне палитры — `themed(светлый, тёмный)`.
- `ink` в тёмной теме светлый. **Любой большой тёмный блок** (шапка, «ближайшая встреча», герой абонемента,
  открытая быстрая кнопка) — только `var(--color-panel)` / `var(--color-on-panel)` (`COLOR.panel` / `COLOR.onPanel`,
  Tailwind `bg-panel` / `text-on-panel`): `#22302F` (тёмная бирюза) в обеих темах, текст `#F4F2EC` / `#ECEBE6` — не превращается в белое пятно.
- Тёмная тема тёплая (09.11): бумага `#161513`, карточка `#1E1D1B`, sunken `#272623`, боковая панель `#1A1917`.
  Кнопка на панели — `background: var(--color-on-panel); color: var(--color-panel)`.
- Заливка `ink` для «выбрано» **запрещена** (в тёмной теме — слепящий белый прямоугольник): выбранное — accent-soft + рамка accent (см. ниже).
  `bg-ink` допустим только на маленькой нейтральной кнопке (например, «Вернуть» в тосте).
- `bg-white` и `text-white` в тёмной теме тёмные: это карточка и текст на заливке. Настоящий белый поверх фото — `text-photo` или `COLOR.onPanel`.
- Затемнение под окном — `bg-overlay` или `bg-black/50`, не `bg-ink/…`.

## Текст

IBM Plex Sans — весь текст, **в том числе деньги и время** (09.11). Числа — класс `.num` или `<Money>`:
Plex Sans + `font-variant-numeric: tabular-nums lining-nums` — все цифры одной ширины, столбцы не прыгают,
в строке один шрифт. Число внутри фразы — `.num-inline` / `<Money inline>` (шрифт и вес фразы, ровные цифры).
IBM Plex Mono — **только** `.mono` / `.code`: коды (#4821, номер счёта) и плотные таблицы ≤ 14 px.
Диапазон времени не рвём: `white-space: nowrap` на «19:00–21:00».
Веса только **400 / 500 / 600**. Строка 1.5 у текста, 1.2 у заголовков.
Роли текста для inline-стилей — `TYPE` в `tokens.ts` (`style={{ ...TYPE.rowTitle }}`):
`screenTitle` 28/600 · `cardTitle` 20/600 · `rowTitle` 16/600 · `text` 16/400 · `secondary` 14/400 · `overline` 12/600 капс · `note` 12/500.
Подпись раздела («КОШЕЛЁК») — класс `.ui-overline` (Sans 12/600 капсом, ink-60), не Mono в разрядку.

| Токен | px | Tailwind | Где |
|---|---|---|---|
| caption | 12 | `text-caption` | подписи, вкладки меню, бейджи (минимум!) |
| small | 14 | `text-small` | вторичный текст, плотные таблицы, подписи полей |
| body | 16 | `text-body` | основной текст, поля на телефоне |
| title | 20 | `text-title` | заголовок карточки, шапка /m, шторки |
| heading | 28 | `text-heading` | заголовок экрана |
| display | 40 | `text-display` | публичные страницы и одно главное число (`SummaryCard size="lg"`) |
| hero | 56 | `text-hero` | только hero |

Отступы — шаг 4: **4 / 8 / 12 / 16 / 24 / 32 / 48** (`--space-1…7`, в Tailwind `p-1/2/3/4/6/8/12`),
поля экрана на телефоне 16. Скругления (09.11) — **на телефоне только 8 / 16 / круг**:
**8** — кнопки, поля, чипы, бейджи, `ChoiceCard` (`--radius-control`, `SHAPE.control`);
**16** — карточки, группы строк, шторки (`--radius-card` = `--radius-sheet`, `SHAPE.card`);
**круг** — аватар, точка, счётчик, ручка шторки (`--radius-pill`, `SHAPE.pill`).
**0** (`--radius-grid`) — только десктоп Grid House (таблицы, окна по центру). 6/10/12/14/22 — нельзя;
сторож `guard_design_foundation_2026_11` проверяет общие компоненты. Тень одна —
`--shadow-pop`, только для всплывающего. Слои: `dropdown 40 · sticky 90 · nav 100 ·
sheet 200/201 · dialog 10050 · toast 10100 · tooltip 10200`.

Высота управления берётся из `--control-h`: **44 px** на телефоне и во всём `/m`
(оболочки ставят `html[data-density="touch"]`), **36 px** на компьютере.

## Компоненты — когда что брать

| Компонент | Когда |
|---|---|
| `Button` | Любая кнопка. `primary` — **единственная** залитая бирюзой кнопка, **одна на экран/шторку** (в шапке экрана или в подвале шторки); `secondary` — второе («Оставить»); `quiet` — третье; `danger` — необратимое. `size="sm"` (36 px видно, 44 px под палец) — действие **внутри строки**, только `secondary`/`quiet`: «Оплата · 120 ₾» в строке — `secondary sm`, не бирюзовая. `loading` на время запроса (блокирует повторный тап). `block` — во всю ширину в шторке. Чёрных «пилюль» и круглых плавающих «главных» кнопок нет. |
| `ListGroup` + `ListRow` (+ `ListTime`, `ListIcon`, `ListAvatar`) | **Любой список строк** на телефоне: брони, сессии, история, должники, клиенты, команда, строки шторок. Группа — одна карточка (радиус 16, линии между строками), подпись сверху («СЕГОДНЯ», «НОЯБРЬ»), `aside` — итог справа. Строка ≥ 48 px: `lead` (время 52 px / значок / аватар), `title` + `subtitle` (переносятся, не режутся), `meta` (бейджи), `trail` (сумма / бейдж, не переносится), `trailSub`, `action` (тихая кнопка вне нажимаемой области). `onClick` / `to` — вся строка нажимается, «›» сам. `tone="danger"\|"pending"` — полоса слева (вместе со словом!). `bare` — внутри шторки. |
| `Switch` (09.11 фаза 3) | Вкл / выкл: рабочий день, «показывать на сайте». `on`, `onChange`, `label` (для диктора). 52×44, бирюзовая дорожка. В строке — в `action` у `ListRow`. |
| `Counter` (09.11 фаза 3) | Один вид счётчика: круг 18 px, 12/600, обводка цветом фона (`--counter-ring`). `tone="danger"` — «требует внимания» (заявки, анкеты); `tone="accent"` — новости (колокольчик). 0 не рисуется, >99 — «99+». |
| `PageTabs` (09.11 фаза 3) | Вкладки страницы («Операции / Итоги дня / Скидки»): 16/600, выбранная — подчёркивание accent. Фильтр внутри раздела — `Segmented`, не PageTabs. |
| `Input size="hero"` (09.11 фаза 3) | Сумма — главное поле шторки денег: 64 px, 28/600, «₾» того же кегля. |
| `ChoiceCard` + `ChoiceGroup` | Выбор карточкой: способ оплаты, тип помещения, вариант фильтра. `layout="row"` (значок, название, описание, `trail`, кружок-отметка справа) или `"tile"` (2–3 в ряд, `ChoiceGroup columns={3}`). |
| `Sheet` | Любое окно/шторка. Снизу на телефоне, по центру на компьютере, выше нижнего меню, Esc, свайп, фокус внутри, подвал с кнопкой всегда виден. Главную кнопку — в `footer`, первой. |
| `useConfirmDialog().confirm({…})` | Вместо `confirm()`. Кнопки называют действие; `tone: 'danger'` для необратимого. Вне компонентов — `confirmAction({…})`. |
| `undoToast(msg, onUndo)` | После мелкого удаления/отмены — «Вернуть» 5 секунд вместо «Вы уверены?». |
| `StatusBadge` | Любой статус брони/оплаты/сессии. `kind="booking" \| "payment" \| "session"`, `audience="staff"` для админки, `variant="dot"` для таблиц. Слова — только из `statuses.ts`. |
| `Field` + `Input/TextArea/Select` | Любое поле. Подпись всегда видна, ошибка под полем говорит, что сделать. `kind` = `money / integer / phone / email / search / name / password` — правильная клавиатура и автозаполнение. |
| `Chip`, `Segmented` | Фильтры (много, с переносом; ряд вбок — `ui-chip-row ui-chip-row--scroll` с затуханием) и выбор 1 из 2–4 в строку. Выбранное — accent-soft + рамка accent, без галочки. |
| `Skeleton`, `SkeletonList` | Пока данные грузятся. **Никогда** не показывать «пусто» / «0 ₾» до ответа сервера. |
| `ErrorBar` | Загрузка упала. С `staleAt` — «Показаны данные на 14:05», хорошие данные не затираем. |
| `EmptyState` | Данные загрузились, и их правда нет. Всегда с подсказкой, что делать, и действием, если оно есть. Пустой экран целиком — `illustration="chair" \| "plant" \| "cup" \| "door"` (спокойная линейная картинка 120 px), пустой блок внутри экрана — `icon` 24–32 px. `secondaryAction` — тихое второе действие. Текст тёплый и по делу: «Сегодня свободный день» / «Выберите время — займёт минуту», не «Нет данных». |
| `PageHeader` / `MobilePageHeader` | Шапка экрана. На /m: корень раздела — `variant="large"` (28/600, `subtitle` 14 ink-60, `action` справа — главная кнопка экрана, поля 16, без «←»); внутренний экран — `variant="bar"` (липкая строка 56 px, «←», 20 px). Стрелка «←» только возвращает назад. Подзаголовок не повторяет заголовок и не пишет «Всего: 8 · показано: 8». |
| `Money`, `formatGel`, `formatDateLabel`, `formatDayMonth`, `formatTime` | Все суммы и даты: «1 250 ₾», «вт, 29 сентября», «29 сентября», «14:05». Дата из базы (UTC) — `{ timeZone: BATUMI_TZ }`. Цвет суммы — только `tone` у `Money` (см. ниже), не свои `color`. |

## Правила

1. **Текст не бледнее ink-60.** ink-40/30/20/10 — только линии, рамки, иконки, неактивное.
2. **Меньше 12 px — нельзя.** Размеры только из шкалы.
3. **Цвет только для статуса.** Зелёный — оплачено/ок, янтарный — ждём, красный — долг/отмена/опасно.
   Бирюза — «выбрано», фокус и главная кнопка, больше нигде. Никаких фиолетовых, синих и градиентов для красоты.
   **Долг — всегда красный (danger), никогда не янтарь.** Расход в кассе — не красный (чернила).
4. **Кнопки называют действие**: «Отменить 6 броней» / «Оставить», а не «ОК» / «Да» / «Отмена».
5. **Обращение — «вы»** (с маленькой буквы), везде, включая /m. Состояния — от «мы»: «Сохраняем…», «Бронируем…».
6. **Загрузка ≠ ошибка ≠ пусто.** Три разных состояния: Skeleton → ErrorBar → EmptyState.
7. **Никаких `confirm()` / `prompt()` / `alert()`** в новом коде. Числа — полем `Input kind="integer|money"` в шторке.
8. **Никакого `#fff` и `#000`** — только токены. Новый цвет сначала появляется в `@theme` и `tokens.ts`.
9. **Одна тень** (`--shadow-pop`) и только у всплывающего; остальное разделяем тонкими линиями.
10. **Нажатие — 0.97 за 140 мс**, шторка 220/180 мс, без «лесенок» списков. При «уменьшить движение» — без сдвигов (MotionConfig `reducedMotion="user"` в App).

## Волна 4 — админка (шаг 0, 01.10)

### «К оплате» и «✓ оплачено» (решение владельца В2)

Владелец: неоплаченные брони должны бросаться в глаза, чтобы админы были внимательнее.
Сумма «к оплате» по брони — только из `computeDueByBooking` (`src/utils/dueAmounts.ts`), своих формул нет.

| Состояние | Когда | Как выглядит |
|---|---|---|
| **к оплате** | `due > 0` — прошедшая или будущая | тон **danger**: заливка/рамка `--status-danger-bg`, текст `--status-danger-fg` «к оплате 36 ₾» + значок `AlertCircle` |
| **✓ оплачено** | запись в dueMap есть, `due ≤ 0` | спокойный тон **ok**: `--status-ok-bg` / `--status-ok-fg`, «✓ оплачено» |
| ничего | записи нет (абонемент без доплаты, обслуживание, прощённая) | не рисуем ни цвета, ни подписи |

Всегда цвет **и** текст (и значок), не только цвет. Где показывать: шахматка (на каждой брони;
на 30-минутной — значок в углу с той же подписью в `aria-label`/`title`), «Сегодня» на компьютере
и телефоне, список броней. Легенда шахматки объясняет оба состояния словами «к оплате» / «✓ оплачено».

Прошедшие брони (сервер отдаёт их как `completed`) теперь тоже получают запись в dueMap:
долг ложится на самые свежие списанные брони, покрытые прошедшие — «✓ оплачено». Долг
клиента от этого не меняется, только то, на какие брони он разложен.

Общий компонент — `src/components/admin/DueBadge.tsx` (не в `ui/*`):

```tsx
const info = dueMap.get(b.id);
<DueBadge due={info?.due} paid={!!info} />            // плашка
<DueBadge due={info?.due} paid={!!info} variant="dot" /> // плотная таблица Grid House
```

## Как собирать экран (09.11)

Фундамент для перекраски /m после ревью клиента, Psy-CRM и админки (09.11). Палитра — по макету
владельца (тёплая бумага, тёмно-бирюзовая панель); рамки у карточек пока оставлены. Всё ниже работает
на токенах, поэтому экраны на токенах перекрашиваются сами.
Сторож: `backend/tests/guard_design_foundation_2026_11.py`.

### Сверху вниз

```tsx
<MobilePageHeader variant="large" title="Сессии" subtitle="Ноябрь"
                  action={<Button icon={<Plus size={18} />}>Сессия</Button>} />  {/* 1. шапка + ЕДИНСТВЕННАЯ главная кнопка */}
<div style={{ padding: '0 16px', display: 'grid', gap: 24 }}>
  <SummaryCard label="Заработано" value={<Money value={1460} />}        {/* 2. итог — одно крупное число */}
               stats={[{ label: 'Долг всего', value: <Money value={240} tone="debt" /> }]} />
  <ListGroup title="Сегодня" aside={<Money value={360} />}>             {/* 3. списки — группы строк по дням/месяцам */}
    <ListRow lead={<ListTime start="10:00" end="10:50" />} title="Анна Ким"
             subtitle="Кабинет 5 · Uni" trail={<Money value={120} />} onClick={…} />
    <ListRow lead={<ListTime start="12:00" end="12:50" />} title="Михаил Абашидзе"
             subtitle="не оплачено" tone="danger"
             action={<Button size="sm" variant="secondary">Оплата · <Money value={120} inline /></Button>} />
  </ListGroup>
  <EmptyState illustration="chair" title="Сегодня свободный день" hint="…" />  {/* пусто — только после загрузки */}
</div>
```

1. **Шапка** — `MobilePageHeader`: корень раздела `variant="large"` (28 / подзаголовок 14 / поля 16),
   внутренний экран `variant="bar"` со «←». Заголовок не дублируется подписью раздела ниже.
   `ListRow` (фаза 3) пропускает `aria-*` (`aria-pressed`, `aria-current`), `data-*` и обработчики
   (`onTouchStart`, `onContextMenu` — долгое нажатие) на нажимаемую часть; `href` + `target` — внешняя
   ссылка (tel:, https; у https — «↗»); `as="div"` — внутри своей обёртки (`SwipeRow as="li"`).
   На ≤ 360 px поля строки 12. Две группы подряд в контейнере с `gap` не получают своих лишних 24 px.
   Пустой список при главной кнопке в шапке — `EmptyState action={{ …, variant: 'secondary' }}`.
2. **Сводка** — `SummaryCard`: одно главное число (28, `size="lg"` — 40), остальное — `caption` или
   `stats` (2–4 ячейки; ненулевая ячейка красится тоном суммы, нулевая серая, ячейка может вести на свой экран).
3. **Списки** — `ListGroup` из `ListRow`. Никаких отдельных карточек на каждую строку, цветных плиток под
   значками, своих скруглений. Подписи групп — дни («Сегодня», «Завтра», «Пн, 16 ноября») или месяцы.
4. **Одна главная кнопка** — `Button variant="primary"` (бирюза), в шапке экрана или в подвале шторки.
   Заливка — `--color-accent-fill` (в светлой = accent, в тёмной темнее `#3E6F6A`, текст `#F2F5F4` 5.2:1),
   чтобы широкие кнопки в тёмной теме не «кричали» мятным. Шапка `.ui-m-header` в тёмной теме — цвета страницы.
   Действия в строках — `Button size="sm" variant="secondary" | "quiet"`. Подвал шторки: главная `block` + крестик сверху.

### Деньги — одно правило цвета (`<Money tone=…>`)

| Что | Как | Пример |
|---|---|---|
| Движение денег (касса, лента баланса, итоги дня) | `tone="flow"` — знак «+/−» по умолчанию | приход «+9 ₾» **зелёный ok**; расход «−35 ₾» **чернилами** (не красный!); 0 — серый |
| Баланс / остаток | `tone="balance"` | минус «−12,5 ₾» — **danger** (это долг); 0 — серый обычным весом; плюс — обычный |
| Долг, «к оплате» | `tone="debt"` | «120 ₾» — **danger, всегда**, никогда не янтарь |
| Итог, цена, кнопка | без `tone` | цвет от родителя |
| Число во фразе | `inline` | «осталось <Money value={7} inline /> …» |

Красный в деньгах — **только долг**. Сумма — всегда через `Money` (и в кнопках); свои `color` у сумм не ставим.
Если сумма рисуется не компонентом — `moneyToneClass(value, tone)` даёт тот же класс.

### «Выбрано» — один язык

Подложка `accent-soft` + рамка `accent` 1.5 px + текст `accent-ink` 600. Так выглядят `Chip`, `Segmented` и
`ChoiceCard` (способ оплаты, тип помещения, фильтры). Без галочки, которая меняет ширину (у `ChoiceCard` —
кружок-отметка, который есть всегда). **Чёрной заливки для выбранного нет** — ни дня в календаре, ни кабинета,
ни длительности: в тёмной теме это белые слепящие прямоугольники.

### Тёмные панели

Большой тёмный блок — `var(--color-panel)` / `var(--color-on-panel)` (`SummaryCard variant="panel"`), не `ink`.
Не больше одной тёмной плиты на экран. Токен задан в обеих темах: `#22302F` (тёмная бирюза).

### Скругления и текст

`SHAPE.control` 8 (кнопки, поля, чипы, бейджи, `ChoiceCard`) · `SHAPE.card` 16 (карточки, группы, шторки) ·
`SHAPE.pill` (круги). Текст — `TEXT` 12 / 14 / 16 / 20 / 28 (+40 для одного главного числа), роли — `TYPE`.
